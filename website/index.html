Verifiable Evidence

Proof an auditor checks alone

A NOUS dossier carries proof, not promises. An auditor checks it on a disconnected laptop with only the cryptography library — no NOUS, no solver, no network.

"The verifier does not trust the producer. It verifies the producer."

Cost
Total cost cannot exceed the declared cost_cap across every execution path in the proven bound. Universal, not sampled.
Coverage
Over the declared risk threshold, no input satisfies it while escaping every blocking policy. No gap in the net.
HONEST BOUNDARY
Coverage proves there is no gap in the declared blocking net — not that the agent cannot misbehave. Policies are monitors; the signed evidence attests the declared governance was sound and in force. This is coverage, not impossibility. NOUS claims exactly what it can sign, and refuses the rest.
1 — THE AGENT
Probabilistic execution
Build any agent. NOUS sits above as a governance shell and proves the cost ceiling and the coverage net before any model call. If it cannot prove it, it refuses to sign.
2 — THE ARTIFACT
The signed dossier
One self-contained package, Ed25519-signed. Tamper one byte and the signature breaks. Offline and immutable — it never phones home.
3 — THE AUDITOR
Asymmetric verification
Verifies on a disconnected laptop. No NOUS, no solver, no network. The coverage proof is checked by stdlib rational arithmetic; it collapses to 0 < 0.
ZERO VENDOR TRUST · ZERO SOLVER DEPENDENCY · PURE MATH
Producer signs with the solver, once. The auditor verifies with only cryptography.

Governance Layer

Governance & Replay

Declare policies in the source. Enforce them at runtime. Replay every decision deterministically.

Deterministic Replay
Record Once. Replay Forever.
Every sense call, LLM request, and memory write is recorded with a SHA256 hash chain. Replay a run bit-exact — same seeds, same timestamps, same responses. Phase A–D
Policy DSL
Rules in the Source
Declare policies inside world blocks. Native grammar, compiled into the runtime, version-controlled alongside the agents they govern. policy { kind, signal, action }
Intervention Engine
Block. Inject. Abort. Audit.
Five actions at three sites (sense.invoke, llm.request, memory.write). Prompt-hash recompute on message injection closes the audit gap.
Dashboard & CLI
Every Decision, Queryable
List active policies. Query historical interventions by soul, action, or time. Aggregate statistics. nous governance stats log.jsonl
