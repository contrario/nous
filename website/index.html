VCS001-005
Governance Layer

Governance & Replay

Declare policies in the source. Enforce them at runtime. Replay every decision deterministically.

Deterministic Replay
Record Once. Replay Forever.
Every sense call, LLM request, and memory write is recorded with a SHA256 hash chain. Replay a run bit-exact — same seeds, same timestamps, same responses. Phase A–D
Policy DSL
Rules in the Source
Declare policies inside world blocks. Native grammar, compiled into the runtime, version-controlled alongside the agents they govern. policy { kind, signal, action }
Intervention Engine
Block. Inject. Abort. Audit.
Five actions at three sites (sense.invoke, llm.request, memory.write). Prompt-hash recompute on message injection closes the audit gap.

Every Decision, Queryable
