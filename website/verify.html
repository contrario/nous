Verify a NOUS dossier

Cryptographic verification of a signed NOUS dossier (manifest.json or skill_export.zip). Validates the Ed25519 author signature and, when present, the Sigstore Rekor transparency-log anchor (Path-beta dual signing: ECDSA-P-256 leaf signature plus signedEntryTimestamp). The canonical trust path is offline; this page is a convenience surface.

⚙Run offline

For deterministic, third-party-auditable verification, the canonical procedure is to run the verifier that shipped inside the dossier, alongside that dossier's manifest.json and source.nous: 

cd path/to/dossier/
python3 verify_offline.py

DEPENDENCIES: cryptography >= 42 · Python >= 3.11 · NO NOUS INSTALL REQUIRED

The verifier is chosen when the dossier is emitted, to match the evidence that dossier carries. There are no modes to select: a Rekor-anchored dossier ships a verifier that checks the anchor and refuses if the block is absent; a dossier without an anchor ships a verifier that does not expect one. The standalone download that once offered both behind a flag was withdrawn (ADR-0009).
